# Code of Conduct

Fiddlehead adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be kind, be patient, and assume good faith. Welcome newcomers — many people come to this project to
learn how models work. Critique ideas and code, never people. Harassment, insults and personal attacks are not
tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately through the email address
on the maintainer's GitHub profile, or use GitHub's **Report content** option on the comment or issue. Reports are
handled confidentially, and maintainers will act on them as described in the Contributor Covenant's enforcement
guidelines.
